# Datacake Fields Cheat Sheet

Краткая шпаргалка по сущностям `Datacake` для проекта `BS Test WPM`.

Важно:

- Это относительные уровни в процентах, а не реальные откалиброванные `dB`.
- Текстовые поля в `Datacake` лучше создавать вручную.
- Числовые поля лучше сразу заводить с правильной единицей измерения.

## Main Sound Fields

### `NOW_PCT`

- Что показывает: текущий относительный уровень шума.
- Зачем нужен: понять, что происходит прямо сейчас.
- Тип поля: `Number`
- Единица: `%`
- Рекомендуемый widget: `Gauge`

### `HOUR_PCT`

- Что показывает: средний уровень шума за последний час.
- Зачем нужен: видеть сглаженную текущую картину без резких скачков.
- Тип поля: `Number`
- Единица: `%`
- Рекомендуемый widget: `Bar`, `Small Gauge`

### `MEAN_PCT`

- Что показывает: средний уровень шума за всё время после запуска.
- Зачем нужен: видеть общий фон работы устройства.
- Тип поля: `Number`
- Единица: `%`
- Рекомендуемый widget: `Bar`, `Small Gauge`

### `CURRENT_PERIOD_PCT`

- Что показывает: средний уровень шума для текущего периода суток.
- Зачем нужен: оценить типичный уровень именно для текущего времени суток.
- Тип поля: `Number`
- Единица: `%`
- Рекомендуемый widget: `Line Chart`, `Area Chart`

## Day-Part Comparison

### `DAY_PCT`

- Что показывает: средний уровень шума днём.
- Зачем нужен: сравнивать дневной фон с вечером и ночью.
- Тип поля: `Number`
- Единица: `%`

### `EVENING_PCT`

- Что показывает: средний уровень шума вечером.
- Зачем нужен: сравнивать вечерний фон с дневным и ночным.
- Тип поля: `Number`
- Единица: `%`

### `NIGHT_PCT`

- Что показывает: средний уровень шума ночью.
- Зачем нужен: сравнивать ночной фон с дневным и вечерним.
- Тип поля: `Number`
- Единица: `%`

Рекомендуемый widget для `DAY_PCT`, `EVENING_PCT`, `NIGHT_PCT`:

- `Bar Chart` на 3 серии

## Signal Status

### `SIGNAL_STATE`

- Что показывает: текстовое состояние уровня. Текущие значения прошивки: `LOW`, `OK`, `CLIP`.
- Зачем нужен: быстро понять состояние без чтения процентов.
- Тип поля: `Text`
- Рекомендуемый widget: `State`, `Status`, `Badge`

Примечание:

- `LOW` - сигнал слишком слабый.
- `OK` - нормальный рабочий диапазон.
- `CLIP` - перегруз или упор в предел ADC.

## Network Status

### `ONLINE`

- Что показывает: устройство онлайн или нет.
- Зачем нужен: базовый индикатор жизни устройства.
- Тип поля: `Boolean`
- Рекомендуемый widget: `Status`

### `WIFI_PCT`

- Что показывает: уровень Wi-Fi в процентах.
- Зачем нужен: понять качество связи.
- Тип поля: `Number`
- Единица: `%`
- Рекомендуемый widget: `Small Gauge`, `Bar`

## Environment

### `TEMPERATURE_C`

- Что показывает: текущую температуру с `SHT31`.
- Зачем нужен: видеть температурный фон рядом с шумовыми измерениями.
- Тип поля: `Number`
- Единица: `C`
- Рекомендуемый widget: `Value`, `Number Card`

### `HUMIDITY_PCT`

- Что показывает: текущую влажность с `SHT31`.
- Зачем нужен: видеть условия среды, в которых идут замеры.
- Тип поля: `Number`
- Единица: `%`
- Рекомендуемый widget: `Value`, `Number Card`

## Time And Context

### `CURRENT_PERIOD`

- Что показывает: текущий период суток: `day`, `evening`, `night`.
- Зачем нужен: понимать, к какому периоду относится текущая статистика.
- Тип поля: `Text`
- Рекомендуемый widget: `Text`, `Status`

### `LAST_UPDATE_TS`

- Что показывает: время последнего актуального обновления.
- Зачем нужен: понять, что данные живые и когда они обновлялись.
- Тип поля: `Text`
- Рекомендуемый widget: `Text`

Примечание:

- До синхронизации времени `LAST_UPDATE_TS` может показывать uptime-формат вроде `0d, 0h, 5m`.
- После синхронизации времени поле начинает показывать реальное время.

## Uptime

### `UPTIME_MIN`

- Что показывает: сколько минут устройство работает без перезапуска.
- Зачем нужен: быстрый контроль коротких тестов и ранних сбоев.
- Тип поля: `Number`
- Единица: `min`
- Рекомендуемый widget: `Number Card`

### `UPTIME_HOURS`

- Что показывает: сколько часов устройство работает без перезапуска.
- Зачем нужен: главный индикатор стабильности.
- Тип поля: `Number`
- Единица: `h`
- Рекомендуемый widget: `Number Card`

### `UPTIME_DATE`

- Что показывает: человекочитаемый uptime, например `0d, 3h, 42m`.
- Зачем нужен: быстро читать uptime глазами без пересчётов.
- Тип поля: `Text`
- Рекомендуемый widget: `Text`

## Minimal Recommended Dashboard

- `NOW_PCT` -> большой `Gauge`
- `HOUR_PCT` -> карточка
- `MEAN_PCT` -> карточка
- `SIGNAL_STATE` -> `Badge`
- `DAY_PCT`, `EVENING_PCT`, `NIGHT_PCT` -> один `Bar Chart`
- `CURRENT_PERIOD_PCT` -> `Line Chart`
- `ONLINE` -> `Status`
- `WIFI_PCT` -> маленький `Gauge`
- `UPTIME_HOURS` -> карточка
- `LAST_UPDATE_TS` -> текст

## Fields Better Created Manually

Рекомендуется вручную создать в `Datacake` следующие поля, если они не появились в интерфейсе:

- `SIGNAL_STATE` -> `Text`
- `LAST_UPDATE_TS` -> `Text`
- `UPTIME_DATE` -> `Text`
- `UPTIME_MIN` -> `Number`
- `UPTIME_HOURS` -> `Number`

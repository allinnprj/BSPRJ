# BS Test WPM

Тестовый проект для чистого перезапуска на `ESP32` с:

- микрофоном `MAX9814` как временным аналоговым источником
- OLED `SSD1306 128x64` по I2C

## Статус

- Тип: локальный временный тестовый проект
- Текущая версия: `0.1.20-test`
- Текущая сборка: `21`
- GitHub в этом проекте не используется
- Следующий микрофонный этап: `INMP441`

## Цель

Развивать проект пошагово с чистой базы `ESP32`:

- вывод текста на OLED
- живой уровень микрофона
- краткосрочная и долгосрочная статистика шума
- Wi-Fi и модуль времени только после стабилизации базового цикла

## Текущее поведение

Прошивка сейчас показывает на OLED относительные уровни звука:

- `Now` - текущий уровень
- `H` - среднее за последний час
- `M` - среднее за всё время работы с момента запуска
- сообщение о прогреве, пока часовое окно ещё не заполнено

Это относительные уровни, а не откалиброванные `dB`.
Этот перезапуск специально не включает активный Wi-Fi и реальное время, пока не стабилизирована новая база.

## Сборка

```powershell
pio run
```

## Секреты

- Локальные учетные данные хранятся в `include/secrets.h`
- `include/secrets.h` исключен из Git

```powershell
pio device monitor -e esp32dev -b 115200
```
